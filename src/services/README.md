# services

这里封装数据持久化、备份和外部接口调用。

## 高德服务

`amap.ts` 是调用方使用的稳定入口，具体实现放在 `amap/`：

- `inputTips.ts`：地点联想、结果规范化、去重和短期缓存。
- `routeApi.ts`：驾车与骑行代理接口请求和响应解析。
- `routePlanner.ts`：路线缓存、请求去重、并发队列和限流冷却。
- `types.ts`：高德服务的公共及内部类型。
- `utils.ts`：坐标格式和路线键生成。

组件不应直接依赖 `amap/` 内部文件；统一从 `amap.ts` 导入，以便服务实现可以独立演进。
