# 旅行轨迹记录与规划工具 · 使用说明书

这是一款在本机保存旅行资料的 Windows 工具。你可以先安排每日路线，旅行结束后补充实际行驶记录、评分、照片和备注，再把它们整理成路书、游记和年度回顾。

本说明按日常使用顺序编写。第一次使用建议从“第一次使用”开始；已有旅程的用户，可以直接通过目录找到要完成的操作。

> 适用版本：**0.6.6**，说明更新日期 **2026-10-12**。本文按当前工作区功能编写。已经生成的 EXE 保留其打包时的功能和说明；更新 README 不会自动更新旧 EXE。

已经用过软件的用户，可以重点查看[途经点行驶预估](#waypoint-estimates)、[道路片段多选与地图核对](#road-multi-select)和[区间道路名称修正](#road-interval-names)。其他日常操作仍可按下面的目录查找。

## 一、先了解软件能做什么

### 1. 根据你的目的选择入口

| 你想做的事 | 从哪里开始 |
| --- | --- |
| 安排还没出发的旅行 | 顶部“规划” |
| 补录已经完成的旅行 | “复盘 → 整理记录” |
| 查看整趟旅行的路线和照片 | “复盘 → 路书浏览” |
| 查看累计里程、评分和道路记录 | “复盘 → 数据统计” |
| 找到需要补录或重新分析的路段 | “数据统计 → 统计总览 → 待处理清单” |
| 核对某个道路片段的位置和分类 | “统计总览 → 历史路线道路分析 → 人工修正” |
| 修正某一段轨迹继承了错误道路名称的问题 | “人工修正 → 轨迹区间道路标注 → 道路名称（可选）” |
| 查看到某个途经点要开多远、多久 | “规划”中选中具体路段 → 详情中的“途经点” |
| 找到某个地点、道路或照片 | 顶部“搜索” |
| 导出可阅读、可打印的行程安排 | “规划”中选中旅程后，“导出规划路书” |
| 把完成的旅行发给别人阅读 | 打开一本复盘路书后，“导出路书” |
| 保存一份可以恢复的数据 | 顶部“备份 → 导出备份” |

### 2. 理解旅程、日期和路段

软件把旅行分成三层：

- **旅程**：一次完整旅行，例如“川西七日自驾”。
- **日期**：旅行中的某一天。
- **路段**：当天的一段行驶，例如“酒店 → 景区”“景区 → 下一座城市”。

同一天可以有多条路段。建议在需要分别记录路线、评分或照片时拆成多段，后续更容易整理。

“规划”与“复盘”分别保存未来行程和已经完成的行程。规划旅程可以在结束后转入复盘，继续使用原来的日期、路段和路线。

### 3. 使用前需要知道的边界

- Windows 桌面版支持本地照片库、直接导出 PDF 和完整 ZIP 备份；普通浏览器页面没有相同的桌面能力。
- 软件没有账号登录和云端自动同步。旅程保存到本机，换电脑需要导出、导入备份。
- 地图底图、地点联想、新路线计算和在线道路补全需要网络。离线时可查看已有记录，但不能把已保存轨迹当作完整离线地图。
- 地图上的路线通常来自路线规划或手工修改，**不等于车辆实际 GPS 轨迹**。实际里程、用时和费用需要自行填写。
- 照片库关联本地原图，不把原图复制进旅程。原图需要单独保存和备份。

## 二、第一次使用

### 1. 打开桌面软件

1. 双击 Windows x64 便携 EXE。日常使用无需安装 Node.js 或下载源码。
2. 首次打开时，如果没有地图 Key 且尚未跳过教程，软件会显示地图服务申请引导。
3. 已有备份的用户，可以先阅读[备份与恢复](#backup)，再导入自己的数据；没有备份则直接开始创建旅程。

“便携”表示免安装，数据仍保存在当前 Windows 用户的数据目录中。仅复制 EXE 不会复制旅程或照片。

### 2. 配置地图服务

**入口：顶部“配置地图服务”；配置后显示为“地图服务设置”。**

1. 打开配置窗口，进入“API 注册方法”，按软件内的引导申请自己的高德 Key。
2. 申请时选择 **Web 服务**类型。这里不使用 Web 端 JS API Key，也不需要填写 JS API 安全密钥。
3. 切换到“Key 配置”，粘贴 Key。
4. 点击“保存并启用”；已有 Key 时，输入新值后点击“替换 Key”。
5. 尝试在新增路段时搜索一个明确地点，选择候选结果，再查看路线是否能正常计算。

账号认证、接口权限和可用额度以高德平台实际显示为准。软件显示“已配置”仅表示读到了 Key，真实可用性要看搜索、路线请求的结果。

如果暂时没有 Key，可以点击“跳过”或“稍后设置”，先阅读说明、查看已有记录，之后再从顶部入口配置。

### 3. 第一次使用的建议顺序

1. 创建一个规划旅程。
2. 添加一条有明确起终点的路段。
3. 选中这条路段，等待路线计算，核对地图、里程和时间。
4. 再添加剩余日期和路段。
5. 导出规划路书，检查整趟安排。
6. 完成一次备份导出，熟悉数据保存方式。

先用一条路段确认搜索和路线正常，再录入大量内容，会更容易发现 Key、网络或地点选择问题。

## 三、认识界面与保存方式

### 1. 顶部入口

| 入口 | 作用 |
| --- | --- |
| 复盘 | 进入已完成旅行的“路书浏览”“整理记录”“数据统计” |
| 规划 | 创建和调整未来行程 |
| 搜索 | 在规划和复盘资料中查找记录 |
| 备份 | 导出、导入备份，以及查看备份包含什么 |
| 帮助 → 使用说明（README） | 在软件内阅读本说明 |
| 配置地图服务 / 地图服务设置 | 设置 Key、查看申请教程 |

“路书浏览”适合阅读，“整理记录”适合修改，“数据统计”适合汇总比较。它们都位于“复盘”工作区。

### 2. 地图工作区

“规划”和“复盘 → 整理记录”都使用地图工作区：

- **旅程编辑面板**：新增旅程、为某一天新增路段，也会显示旅程管理内容。
- **地图区域**：查看所选范围的路线、起终点和照片位置。
- **年份 / 旅程 / 日期 / 路段筛选**：决定当前查看哪一组记录。
- **详情 / 相册面板**：查看或编辑当前路段；相册用于复盘照片。

旅程编辑面板默认收起。点击侧边“旅程编辑”展开；没有旅程时，也可通过“前往旅程编辑”进入。两侧面板都可以收起，给地图腾出空间。窄窗口下通过“旅程编辑”“详情”“相册”标签切换内容。

旅程、日期旁的 **“⋯”** 是操作菜单。管理旅程、创建副本、插入日期和排序等操作放在这里。

### 3. 哪些操作需要点击保存

| 操作 | 什么时候生效 |
| --- | --- |
| 新增旅程、新增路段 | 点击“添加旅程”“添加路段”后提交 |
| 管理旅程中的标题和起止日期 | 点击“保存”后提交 |
| 路段详情中的名称、日期、地点、路线设置、评分、实际记录和备注 | 点击“保存全部”，或在详情编辑中按 Ctrl + S |
| 旅程和当天路段排序 | 调整后立即生效；“完成”用于收起排序面板 |
| 照片备注 | 点击“保存备注”；切换照片或关闭查看器时也会尝试保存 |
| 照片地图位置 | 点击“保存位置” |
| 道路片段表格修正 | 单行用“保存修正”，批量用“保存选中”，所有改动用“全部保存” |
| 地图上的道路区间标注 | 新标注用“保存区间标注”，修改已有标注用“保存修改” |
| 游记 | 点击“保存游记”；下载 Markdown 与保存到旅程是两个操作 |

已经提交的旅程记录会自动写入本地。表单里尚未提交的内容仍是草稿，不能把“已经输入”当作“已经保存”。出现保存失败或“重试保存”提示时，应先处理提示，再关闭软件。

切换记录时，如果出现“放弃未保存的更改”，选择放弃会丢弃当前草稿。希望保留内容时，应取消切换，先保存当前编辑。

道路修正表格和地图区间标注也各自有草稿。切换人工修正对象、从待处理清单转到其他记录、开始或重试道路分析时，如出现放弃更改提示，应先确认草稿是否还需要。仅点击表格中的道路名称查看位置，不会保存修正。

## 四、从零规划一次旅行

### 1. 新建规划旅程

**入口：顶部“规划” → 展开“旅程编辑” → “新增旅程”。**

1. 填写旅程标题，例如“周末山水两日游”。
2. 填写开始日期和结束日期，例如 2026-10-10 至 2026-10-11。
3. 点击“添加旅程”。结束日期不能早于开始日期。
4. 在“旅程”筛选中选中刚创建的旅程。

旅程会归入创建时所在的工作区。补录已经完成的旅行时，可直接在“复盘 → 整理记录”中创建。

### 2. 为某一天添加路段

**入口：旅程编辑面板 → “新增路段”。**

1. 选择目标旅程。
2. 选择“路段日期”。新增路段的日期选项来自旅程起止范围。
3. 填写“路段名称”，例如“家 → 山区民宿”。
4. 输入起点，从联想列表中选择具体地点。
5. 输入终点，同样选择具体候选地点。
6. 按需要展开“途经点（可选）”“路线设置”“评分与备注（可选）”。
7. 点击“添加路段”。

输入地点名称后，**还要选择联想候选**，使地点拥有对应坐标。遇到同名地点时，要核对城市和地址，避免路线落在其他地区。

新增路段表单会优先沿用当前有效的旅程、日期选择。提交前仍应核对，避免把路段加到错误日期。

### 3. 添加途经点

想让路线经过景区、服务区或某个城镇时：

1. 展开“途经点（可选）”。
2. 点击“+ 添加途经点”。
3. 输入地名并选择联想结果。
4. 添加其他途经点，使用上移、下移按钮调整顺序；不需要的点可以删除。
5. 确认顺序为“起点 → 途经点 1 → 途经点 2 → 终点”。

只有名称、没有有效坐标的途经点会阻止正式路线计算。不要用一个未解析的地名代替已经选中的地点。

<a id="waypoint-estimates"></a>

#### 查看到每个途经点的行驶距离和时间

**入口：规划 → 选中旅程、日期和具体路段 → 详情中的“途经点”。**

1. 先保存路段的起终点和途经点，退出详情编辑状态。
2. 在每个途经点下方查看“距起点”和“预计行驶”。
3. 在上方“路线预估”中查看“全程预计里程”和全程预计行驶时间。
4. 如果显示“待计算”，点击“重新计算路线、费用和时间”，等待完成后再核对。

途经点数值是**从本路段起点出发，按途经顺序累计到该点**的距离和行驶时间，不是相邻两个途经点之间的数值。例如第一个点距起点 80 公里、第二个点距起点 125 公里，两个点之间的预估距离为 45 公里。预计时间不含游览、休息或其他停留时间。

| 显示内容 | 怎样处理 |
| --- | --- |
| 待解析坐标 | 编辑该途经点，重新选择地点候选并保存 |
| 待计算 | 核对地点后，使用“重新计算路线、费用和时间” |
| 正在计算途经点预估… | 等待计算完成 |
| 暂无可靠数据 | 当前路线无法可靠对应到这个途经点，或缺少相应距离、时间；不要当作 0 |

编辑期间不显示这些预估，保存后按当前路线显示。旧路线缺少途经点预估时，不会仅为补这项资料自动覆盖已有路线；需要更新时再手动重新计算，并核对新路线。

### 4. 选择路线类型和策略

| 设置 | 适合的目的 |
| --- | --- |
| 驾车路线 · 高速优先 | 希望优先按高速方案安排 |
| 驾车路线 · 速度优先 | 希望按行驶效率安排 |
| 驾车路线 · 避免收费 | 希望按避免收费的方案安排 |
| 骑行路线（走小路） | 使用骑行接口计算路线 |

驾车策略只对驾车模式生效；选择骑行后不能继续使用驾车策略。骑行结果属于骑行路线，不能因为显示为“走小路”就认定所有路段都允许机动车通行。

### 5. 生成并核对路线

1. 添加路段后，在筛选区依次选中 **旅程、日期、具体路段**。
2. 有有效地点和地图服务时，软件可为选中的具体路段自动计算缺少的路线。
3. 等待加载完成，核对地图是否连接正确地点、是否按途经点顺序行驶。
4. 在详情的“路线预估”中查看预计行驶时间、预估过路费等结果。
5. 需要刷新时，点击“重新计算路线、费用和时间”。

全部旅程或全年总览主要查看已有路线，不会为每一条缺失路线自动发起计算。如果总览中缺线，先选中具体路段检查。

预计时间是路线行驶时间，不包含游览、休息、住宿等安排；预估过路费以实际收费为准。缺少结果时显示待计算或待补全，不代表免费或零耗时。

### 6. 安排完整行程

例如两日旅行可以这样组织：

| 日期 | 路段 | 建议记录 |
| --- | --- | --- |
| 第一天上午 | 家 → 景区 | 途经点、路线策略、出发提醒 |
| 第一天下午 | 景区 → 民宿 | 终点地址、停车或住宿备注 |
| 第二天 | 民宿 → 家 | 返程路线及沿途停留点 |

逐段添加后，选择“全部日期”查看整趟路线，选择某一天查看当天路线。用当天和旅程汇总检查里程、预计驾驶时间，另行预留游览和休息时间。

### 7. 导出规划路书

**入口：规划工作区 → 选中具体旅程 → “导出规划路书”。**

1. 确认需要的路段已经保存、路线预估已经完成。
2. 点击“导出规划路书”。没有选中具体规划旅程时，按钮不可用。
3. 桌面版选择“导出 PDF”并指定保存位置，或选择“下载 HTML”。
4. 打开导出的文件，检查逐日行程、汇总、路线地图、途经点、路线偏好和备注。

**导出的是整趟规划旅程，不受当前日期或路段筛选限制。** 即使地图只选中了第一天，文件仍包含整个旅程。

规划路书只使用已保存的规划资料，不包含复盘实际记录、评分、复盘标签和游记。未计算项目会保留待补全说明，导出不会自动重新规划路线。

导出时联网获取地图底图并嵌入文件，完成后可离线阅读。获取失败时仍保留路线示意图，并说明底图缺失。浏览器版可下载 HTML，再通过浏览器打印保存为 PDF。

## 五、调整旅程、日期和路段

### 1. 修改旅程标题和起止日期

**入口：旅程筛选旁“⋯ → 管理旅程”。**

1. 找到目标旅程，点击“编辑”。
2. 修改标题、开始日期或结束日期。
3. 点击“保存”，或点击“取消”放弃。

修改起止日期用于调整旅程范围，**不会自动把已有路段整体平移到新日期**。需要移动某条路段时，在其“编辑详情”中修改日期；需要在行程中插入或删除一天时，使用下面的日期操作。

### 2. 复制一份旅程

**入口：选中旅程 → 旅程旁“⋯ → 新建副本”，或管理旅程中的副本操作。**

副本拥有独立的旅程、日期和路段，适合保留原方案后尝试另一套安排。复制后先核对名称、起止日期、每条路段日期和路线，再修改。

副本不会复制原旅程的路段照片关联。需要照片时，应在副本中重新选择和关联。

### 3. 调整旅程显示顺序

在“管理旅程”中，使用“排序”菜单的上移、下移、置顶或置底操作。显示顺序调整不会改变旅程日期，也不会改变统计使用的日期。

### 4. 插入一天

**入口：选中具体旅程和日期 → 日期旁“⋯ → 插入下一天”。**

软件在所选日期之后插入空白一天，把后续日期及其路段顺延一天，并把旅程结束日期延后一天。适合在原计划中增加一天停留。

插入后选择新日期，再添加路段。它不是单纯增加一个标签，而是会调整后续行程日期。

### 5. 删除一天

**入口：选中日期 → 日期旁“⋯ → 删除当天”。**

确认后删除当天及当天所有路段，并将后续日期提前一天。重要行程应先导出备份，再执行删除。

如果只是取消当天的一段行驶，请删除那条路段，不必删除整天。

### 6. 调整当天路段顺序

**入口：选中日期 → 日期旁“⋯ → 调整路段顺序”。**

1. 当天至少需要两条路段。
2. 拖拽路段，或使用“上移”“下移”。
3. 调整立即生效，点击“完成”收起面板。

单条路段详情的“更多”菜单也提供上移、下移操作。排序不会自动改写起终点，应自行核对前一段终点与后一段起点是否衔接。

### 7. 编辑或删除单条路段

选择具体路段，点击“编辑详情”，修改名称、日期、地点、途经点或路线设置，最后点击“保存全部”。修改路线条件后，应核对重新计算的结果。

删除时使用路段详情的“更多 → 删除路段”，确认后删除软件内的记录及相关关联。删除旅程则会删除其全部日期和路段。删除照片关联或旅程不会删除磁盘上的原图。

## 六、查看地图与查找记录

### 1. 使用四级筛选

| 选择方式 | 查看范围 |
| --- | --- |
| 全部年份 + 全部旅程 | 当前规划或复盘工作区中的全部旅程 |
| 某一年 + 全年旅程 | 该年全部旅程 |
| 某个旅程 + 全部日期 | 整趟旅行 |
| 某个日期 + 全部路段 | 当天全部路线 |
| 某条具体路段 | 单段路线、详情和复盘相册 |

先选择旅程才能选择日期，先选择日期才能选择路段。切换年份会清空原来的旅程、日期和路段筛选；切换旅程也会重置下级选择。

地图、路书库和数据统计的筛选分别操作，不能把其中一个页面的筛选当作所有页面的共同范围。

### 2. 年份如何归档

地图工作区、路书库、统计总览和年度回顾按**旅程开始年份**归档整趟旅行。

例如 2025-12-30 至 2026-01-03 的旅程整体归入 2025 年；不要到 2026 年列表中寻找它。无法判断年份的旅程显示为“未注明年份”。

道路档案和道路足迹里的“记录年份”按记录日期筛选，含义与旅程开始年份不同。

### 3. 选择地图着色方式

| 着色 | 怎样理解 |
| --- | --- |
| 默认 | 日常路线浏览 |
| 风景评分 | 按路段风景评分查看 |
| 难度评分 | 按路段驾驶难度查看 |
| 道路类型 | 按已分析的道路片段类别查看 |

同一时间使用一种着色方式。风景和难度着色需要先选中具体旅程，在全部旅程或全年旅程中不可用。

道路类型颜色如下：

| 颜色 | 道路类别 |
| --- | --- |
| 红色 | 高速公路 |
| 蓝色 | 国道 |
| 青绿色 | 省道 |
| 紫色 | 其他道路，含县乡村道、城市道路等 |
| 灰色 | 未知道路或缺少有效道路分析的路线 |

使用类别复选框控制显示，也可点击“全选”“全不选”。**当前版本的灰色路线由“未知道路”开关控制，“全不选”也会隐藏灰色路线。**

使用“难度评分”着色时，可结合以下档位阅读地图：

| 驾驶难度评分 | 档位 | 地图颜色 |
| --- | --- | --- |
| 1 至不足 5 分 | 难度较低 | 青绿色 |
| 5 至不足 7 分 | 难度一般 | 紫色 |
| 7 至不足 9 分 | 难度较高 | 玫红色 |
| 9 至 10 分 | 难度极高 | 深酒红色 |

同一档位内颜色随分数逐渐加深。未评分的路段显示灰色；这些颜色表达你填写的主观驾驶难度，不表示实时路况或是否允许通行。切回“道路类型”后，应按道路类别图例读图。

展开地图上的道路统计图例，可查看相应范围的里程和待核实信息。总览中悬停或点击轨迹可查看当前范围内的经过次数；次数来自路线记录，不是实时车辆定位。

### 4. 全局搜索

**入口：顶部“搜索”，或 Ctrl + K。**

1. 输入旅程名、地点、道路编号、备注等关键词，例如 `G316`。
2. 需要缩小范围时，用空格输入多个关键词；结果需同时匹配所有关键词。
3. 查看结果及命中原因，点击需要的记录。
4. 软件切换到对应工作区和记录；照片结果可打开指定照片，途经点结果可定位地点。

结果会标明“规划”或“复盘”，并列出命中的道路编号、地点或备注等内容；同一关键词可能匹配旅程、日期、路段和照片，点击前先核对旅程与日期。结果较多时，点击“显示更多”继续查看。

搜索范围包括规划和复盘中的旅程、日期、起终点、途经点、路段备注、游记、有效道路分析，以及桌面照片文件名和备注。

道路搜索包含已保存且仍有效的主道路和共线道路身份。例如某个区间主编号为 `G316`，另已标注共线编号 `G210`，搜索任一编号都可找到所属路段；不需要把同一条轨迹复制两份。结果定位到整条路段，需要核对具体共线范围时，再进入人工修正地图。

道路编号搜索依赖当前有效道路分析；没有分析或分析过期时，搜不到不代表没有走过。出现“道路缓存读取失败，道路搜索不完整”时，旅程名称、地点和备注仍可搜索，暂时缺少的是道路搜索资料。照片索引读取失败或当前环境没有桌面照片接口时，照片搜索不可用。先处理提示，再重新打开搜索核对结果。

定位到其他记录时，如果软件提示有未保存的编辑，点击取消会保留当前编辑并留在搜索窗口；先保存，再搜索和定位。

## 七、旅行结束后整理复盘

### 1. 把规划旅程转入复盘

**入口：规划 → 旅程旁“⋯ → 管理旅程” → 目标旅程“更多 → 完成旅程，转入复盘”。**

确认后，原规划旅程转为复盘旅程，软件打开它的路书。已有路线与行程保留，之后可到“复盘 → 整理记录”继续补充。

转入前先保存路段详情草稿；确认转换会放弃尚未保存的详情编辑。

转入复盘是更改原旅程的状态，不是在规划和复盘中各保留一份。如果想保留原计划，可以先创建副本。

没有提前规划的旅行，也可直接在复盘工作区创建旅程和路段。

### 2. 填写实际记录

**入口：复盘 → 整理记录 → 选中具体路段 → 编辑详情。**

1. 展开“实际记录”。
2. 根据自己掌握的信息填写实际里程、实际行驶时间和实际过路费。
3. 选择天气、路况、感受等复盘标签。
4. 点击“保存全部”。

| 字段 | 输入单位 | 建议依据 |
| --- | --- | --- |
| 实际里程 | 公里 | 车辆里程表、可靠行驶记录 |
| 实际行驶时间 | 小时、分钟 | 自己记录的行驶时间 |
| 实际过路费 | 元 | 实际账单或付款记录 |

所有字段都可选。不清楚的项目保留空白；只有确实为零时才填写 0。软件不会用规划结果补成实际记录，也不会从一条路线推算实际车速、停留或拥堵经历。

### 3. 填写评分和备注

- **风景评分**：1–10 分，支持小数，用于记录这段路的风景感受。
- **驾驶难度**：1–10 分，数值越高表示主观驾驶难度越高。
- **备注**：记录路况特点、停车提醒、推荐停留点或旅行感受。
- **复盘标签**：用于整理和检索，可再次点击已选标签取消。

评分与备注都是路段级信息。某张照片或某条命名道路展示的评分，可能来自整个路段，并不表示对照片拍摄点或道路每一米分别评分。

编辑完成后点击“保存全部”。未评分保留为空，不会按最低分参与统计。

### 4. 推荐的复盘顺序

逐日核对路段和日期，补实际记录、评分与备注，再关联照片。最后查看路书和统计，可从[待处理清单](#pending-items)逐条进入需要补充的记录，然后导出备份。

## 八、添加和管理照片

### 1. 照片功能的准备

照片库需要 **Windows Electron 桌面版的复盘工作区**。先选择具体旅程、日期和路段，再打开“相册”。

支持 JPEG、PNG、WebP，单张文件上限 100 MiB。HEIC/HEIF 需要先转换。建议把原图放在稳定目录，尽量不要在关联后随意改名、移动或删除。

同一旅程可登记多个照片目录；同一旅程内不允许重复或相互重叠的目录，例如同时登记一个文件夹及其子文件夹。不同旅程可以分别登记同一个目录，但各自的关联和备注独立管理。

### 2. 扫描并关联照片

**入口：复盘 → 整理记录 → 选中路段 → 相册 → 添加照片。**

1. 点击“添加照片”。没有可用照片库时，按提示选择本地目录；有照片库时可使用已有目录。
2. 扫描目录，软件会检查子目录、读取照片信息并显示扫描结果。
3. 在“选择要关联的照片”窗口中，按文件名、拍摄日期和排序方式筛选。
4. 勾选本路段的照片，也可使用“选择当前筛选结果”。
5. 确认关联到当前路段，等待处理完成。
6. 在路段相册中检查新增缩略图。

**扫描到照片不等于已经添加到路段。** 只有选择并关联后，照片才出现在相应路段相册中。

“仅显示未关联照片”可以帮助筛选候选。没有拍摄时间的照片可能无法按日期筛选到，可清空日期条件后按文件名查找。

### 3. 查看原图和照片详情

点击缩略图打开查看器：

- 使用上一张、下一张或底部缩略图切换照片。
- 滚轮或缩放按钮调整大小，放大后拖动查看。
- 使用旋转按钮调整观看角度。
- 双击图片区域或点击“适应窗口”，恢复默认缩放、角度和位置。
- 点击“查看详情”，查看拍摄时间、方向、GPS、地图坐标、本地路径、大小和备注。

缩放和旋转只是查看操作，不改写磁盘原图。缺少 EXIF 信息不代表照片损坏，软件也不会凭照片内容自动推断拍摄地点。

### 4. 写照片备注与设置封面

在查看器的详情中输入“照片备注”，点击“保存备注”。切换照片或关闭时也会尝试保存，应确认状态没有显示失败。

点击“设为旅程封面”可将当前照片用作封面；已经是封面时可取消。路书库中也可以通过“更换封面”选择该旅程已经关联的照片。

### 5. 把照片放到地图上

有有效 EXIF GPS 的照片可使用照片位置。中国境内的原始 GPS 会转换成地图使用的坐标，详情同时保留原始 GPS 与地图坐标信息。

没有 GPS 或希望调整位置时：

1. 在照片详情点击“在地图上定位”或“调整地图位置”。
2. 在地图上点击拍摄位置，或拖动相机图标微调。
3. 点击地图工具栏的“保存位置”；不保留修改则点击“取消”。

已有原始 GPS 时，可使用“恢复 EXIF 位置”。清除地图位置只取消软件内的定位，不修改照片 EXIF。照片标记也可在地图上点击查看，密集位置会聚合显示。

### 6. 批量处理照片

相册可以搜索文件名或备注、按地图位置筛选。点击“批量选择”，勾选照片后可：

| 操作 | 作用 |
| --- | --- |
| 批量刷新信息 | 重新读取照片信息并刷新相关缓存 |
| 批量恢复 EXIF 位置 | 使用原始 GPS 恢复照片地图位置 |
| 清除地图位置 | 移除软件内的照片位置 |
| 移动到目标路段 | 修改照片在软件中的路段归属 |
| 批量移除 | 移除软件中的照片关联 |

“移动到目标路段”不会移动磁盘原图，“批量移除”也不会删除原图。确认目标路段后再操作。

### 7. 处理目录移动、缺失原图和变化文件

**入口：路段相册 → 相册设置与诊断。**

- **整个照片目录换位置**：选择对应照片库，点击“重新关联”，指定新目录。
- **目录新增了照片**：点击“扫描新照片”，再从候选中选择并关联。
- **个别文件移动或改名**：重新扫描，按界面候选重新关联；查看器也提供“重新关联原图”。
- **文件内容改变**：核对变化后，使用“接受变化并刷新照片”或重新读取照片信息。
- **关联异常**：使用界面提供的一致性检查，核对问题后按提示修复。

扫描问题区域会列出格式、读取等异常。照片库仍有已关联照片时，不能直接移除目录登记；先处理这些关联。移除登记仅影响软件资料，不删除本地目录。

## 九、浏览路书、生成游记与分享

### 1. 打开一本路书

**入口：复盘 → 路书浏览。**

1. 按年份、关键词或复盘标签找到旅程。
2. 点击旅程卡片或“打开路书”。
3. 查看旅程总览、逐日路线、路段记录、照片和统计。
4. 需要修改资料时，回到“整理记录”选择对应路段。

路书库只展示复盘旅程。规划中的旅程需要使用规划工作区，或完成后转入复盘。

### 2. 更换路书封面

1. 在路书库找到目标旅程，点击“更换封面”。
2. 选择该旅程已经关联的一张照片，选择后保存为封面。
3. 需要取消自选照片时，点击“恢复默认封面”。

照片封面需要桌面照片接口。没有照片时仍可使用默认展示，不影响路线和文字记录。

### 3. 生成和保存游记

**入口：打开路书 → “生成游记”；已有游记时显示“查看游记”。**

1. 先补齐需要写入游记的路段、实际记录、评分、标签和备注。
2. 点击“生成游记”，查看预览。
3. 点击“保存游记”，把内容保存到当前旅程。
4. 需要独立文件时，点击“下载 Markdown”。
5. 资料更新后，可点击“重新生成”，检查结果再保存。

游记根据已有资料按规则整理，不调用大语言模型编造旅行经历。重新生成会根据当前记录重建内容；需要保留上一份时先下载。已保存游记随旅程备份保存。

### 4. 导出完成旅行的路书

**入口：复盘 → 路书浏览 → 打开路书 → 导出路书。**

1. 检查逐日记录、照片备注和已保存游记。
2. 在导出面板选择是否包含封面照片，并调整精选照片，最多 12 张。
3. 点击“导出 PDF”或“下载 HTML”。桌面 PDF 会打开保存位置对话框。
4. 打开文件，核对所有日期、路线、照片和统计。

文件包含封面、逐日行程、总览和每日地图、路段与照片备注、游记及统计。地图按道路类型着色，标注起终点、途经点和方向；没有有效分类的部分显示灰色。

导出使用已有路线，获取底图时需要联网。底图失败会保留明确标注的路线示意图，缺少路线或照片时保留说明，不自动补造数据。

HTML 内嵌照片缩略图和获取成功的底图快照，可离线阅读。文件不包含本地原图文件或原图目录。分享前应检查地点、备注和照片是否适合公开。

### 5. 选择合适的分享方式

| 想让对方做什么 | 建议提供 |
| --- | --- |
| 阅读或打印行程、旅行路书 | 导出的 PDF 或 HTML |
| 使用软件 | Windows EXE，对方自行配置地图 Key |
| 在软件中恢复你的旅程和道路分析 | 数据备份；说明导入会替换对方现有数据 |
| 恢复相册并查看原图 | 完整 ZIP 备份，加单独复制的原图目录 |

**路书 PDF、HTML 和游记 Markdown 用于阅读；恢复数据应使用“备份”导出的文件。**

## 十、查看统计、道路档案与年度回顾

### 1. 统计总览

**入口：复盘 → 数据统计 → 统计总览。**

1. 在“统计范围”选择全部旅程、按年份或具体旅程。
2. 查看旅程数、路段数、规划和实际里程、预计和实际驾驶时间、旅行天数。
3. 查看逐旅程明细，点击可排序的表头调整顺序。
4. 通过明细中的记录入口回到对应旅程地图。
5. 查看里程、天数、驾驶时间分布，以及风景、难度评分和道路构成。

顶部可切换“统计总览”“道路档案”“年度旅行回顾”。道路足迹从命名道路表或道路档案进入，完成查看后使用“返回道路列表”回到统计页面。

统计只包含复盘旅程。跨年旅程归入开始年份；实际记录和规划数据分别展示。明细默认按开始日期升序，日期无效或缺失的记录排在有效日期后面。

### 2. 看懂缺失和完整性提示

| 提示 | 表示什么 | 如何处理 |
| --- | --- | --- |
| 待补全 / 未记录 | 对应项目没有足够数据 | 回到路段填写，或保留空白 |
| 已记录 / 部分合计 | 只合计已经有数据的部分 | 不要当作整趟旅行完整数值 |
| 待分析 | 没有道路分类分析 | 按需要运行道路分析 |
| 已过期 | 分析与当前路线或规则不匹配 | 核对路线后重新分析 |
| 道路分析部分完整 | 已有分析，但仍有未完整识别的部分 | 核对现有分类，按需要补分析或人工标注 |
| 完整 | 对应指标所需数据已经完整 | 仍需核对原始记录是否正确 |

没有填写不等于零。部分数据不会伪装成完整值；里程、驾驶时间分档只使用对应数据完整的旅程，不完整记录另行提示。

“正在读取路线分析缓存…”表示软件还在读取已保存的路线资料，应等待完成。出现“路线分析缓存读取失败”时，点击页面提示中的“重试读取”。这时道路构成、命名道路表、道路档案和年度回顾暂不可用，已打开的足迹也不展示结果；旅程里程、驾驶时间和评分记录仍可查看。**读取失败不表示道路里程为零，也不表示没有走过这些道路。**

<a id="pending-items"></a>

### 3. 使用待处理清单补齐记录

**入口：复盘 → 数据统计 → 统计总览 → 展开“待处理清单”。**

1. 先在“统计范围”选择全部旅程、某一年或具体旅程；清单跟随这个范围。
2. 查看每行的旅程、日期、路段和待处理项目。默认列出日期待核对、规划里程待计算、预计驾驶时间待计算或已过期，以及道路分析需要处理的记录。
3. 需要补实际里程、实际驾驶时间或评分时，勾选“显示可选的实际记录与评分”。这些内容允许留空，不是必须全部完成的任务。
4. 点击“编辑记录”，进入对应路段的详情编辑，填写后点击“保存全部”。如果项目是“旅程起止日期待核对”，软件会展开旅程管理；找到目标旅程，点击“编辑”，核对日期后保存。
5. 点击“查看道路分析”，软件会展开历史路线道路分析、选中对应旅程、日期和路段，并将分析范围设为“当前路段”。**此操作只定位，不会立即开始在线分析。** 先核对对象，再决定点击“开始分析”或进行人工修正。
6. 处理完成后回到数据统计，继续检查其他记录。清单较长时使用“显示更多”。

清单按记录计数，一条路段有多个问题时仍占一行。没有待处理项目不代表已经填写所有可选资料，也不保证原记录一定正确。路线资料尚未读取完成或读取失败时，清单暂不判断道路分析完整度。

### 4. 常用统计口径

- 旅行天数按起止日期计算，包含首尾两天；同日往返为 1 天。
- 评分平均值按有评分且里程已知的路段进行里程加权；未评分不按最低分处理。
- 道路里程来自规划路线分析及人工标注，不是车载实测里程。
- 历史累计包含当前选中的复盘旅程，不要把“本次”和“累计”再次相加。
- 涉及旅程数按旅程去重，同一旅程多次走同一道路仍是 1 个旅程，里程继续累计。
- 重复行驶会累计里程，因此累计道路里程不等于地图上去重后的道路长度。

### 5. 命名道路表

在统计总览的命名道路表中，可以按名称、编号、省份搜索，按道路类别和省份筛选，再打开档案或足迹。

高速、国道和省道按道路身份汇总；省道结合省份区分。不同省份的 `S101` 会分别显示，省份待确认和无编号省道也单独列出。

选择年份或单旅程时，默认突出当前范围内的道路；勾选“显示其他历史道路”可查看其他累计道路。搜索、类别和省份筛选只是过滤表格，不会改变道路占比的规划总里程分母。

### 6. 道路档案

**入口：数据统计 → 道路档案 → 搜索、筛选 → 查看档案。** 也可从统计总览的命名道路表进入。

档案展示该道路在全部复盘旅程中的已分析累计里程、涉及旅程数、关联路段数、首次和最近记录日期。

1. 用“记录年份”筛选记录日期。
2. 在列表中查看旅程、日期、所在路段、本道路里程和路段评分。
3. 点击“地图”查看对应路段。
4. 有关联照片时，点击“相册”打开路段照片。

档案里的每条记录是关联路段记录，不直接等于一次经过；评分和照片属于整个路段。分析缺失或过期时，不会推断出当前道路归属。

### 7. 道路足迹

**入口：命名道路表或道路档案 → 查看足迹。**

1. 选择“记录年份”，或查看全部年份。
2. 按图例查看这条道路各位置的经过次数。
3. 悬停或点击轨迹，查看相应位置的次数与关联记录。
4. 点击“查看旅程地图”返回原记录；点击“显示全部记录”取消位置筛选。

足迹仅绘制这条道路已有有效分析和坐标的区间，不绘制整条道路的全国线路。缺少几何、分析过期等情况会显示提示或缺失部分。

经过次数按路线记录统计，双向合计；同一记录里的往返也可贡献多次经过。已标注共线区间可出现在相应道路的足迹中，同一次经过不会因为多个道路编号被重复计数。不确定的重合会保留独立线，涉及旅程数不能代替经过次数。

### 8. 年度旅行回顾

**入口：数据统计 → 年度旅行回顾。**

1. 选择年份。
2. 查看全年已有路线、按规划和实际里程分别选出的最长旅程、常走道路和高评分路段。
3. 使用地图、相册或道路档案入口查看原记录。
4. 桌面版可点击“调整精选照片”，最多选择 12 张；也可恢复推荐或清空选择。
5. 点击“下载年度报告”，生成 HTML，打开后可阅读或通过浏览器打印。

路线资料或照片索引还在读取时，“下载年度报告”暂不可用，等待读取结束后再导出；路线资料读取失败时，先使用页面上的“重试读取”。

最长旅程只比较对应里程完整的旅程；常走道路按涉及旅程数、累计分析里程排序，最多展示 5 条；值得回看的路段展示风景评分至少 7 分的前 5 条。

报告内嵌路线示意图和精选照片缩略图，可离线阅读，**不包含在线底图和原图**。全年地图使用匹配的已保存路线，不自动重新规划。报告照片选择不会修改旅程封面或原图。

## 十一、补全和修正道路分析

本节适合处理“地图有路线但统计不全”“道路类别或编号识别有误”“一段路同时属于多个编号”等情况。

### 1. 补全历史路线道路分析

**入口：复盘 → 数据统计 → 统计总览 → 展开“历史路线道路分析”。**

1. 在下方“人工修正”的旅程、日期、路段选择框中核对目标。也可从待处理清单点击“查看道路分析”，直接定位到对应路段。
2. 选择分析范围：当前路段、当前旅程或全部复盘旅程。“当前路段”和“当前旅程”以人工修正区域选中的对象为准，不要只凭之前的地图筛选判断；“全部复盘旅程”不受统计范围筛选限制。
3. 点击“开始分析”，查看进度和每条路段的状态。
4. 需要停止时点击“取消”；有失败项目时可点击“重试失败项”。
5. 遇到新旧路线差异提示，核对后选择保留原轨迹或“明确替换”。

在线补全会重新请求高德路线。相似路线用于补道路分析；差异较大时需要你决定是否替换。今天返回的方案可能与过去不同，不应为了补统计而未经核对覆盖历史路线。

取消不会自动撤回此前已成功保存的结果。分析需要有效 Key、网络和可调用额度。省份信息证据不足时保持待确认，不强行归入某一省。

开始分析或重试失败项前，先保存道路表格与区间标注的草稿。如出现放弃提示，点击取消会保留草稿且不开始分析；确认放弃后，未保存内容会丢弃。

### 2. 修正已有道路片段

**入口：历史路线道路分析 → 人工修正。**

1. 在人工修正区域选择旅程、日期和路段。
2. 点击表格中的道路名称，或该行非输入区域，上方地图会定位并用黄色实线突出对应片段，表格同时突出当前定位行。尚未选择标注区间时，还会显示定位片段的端点。缺少有效坐标的片段会显示无法高亮提示。
3. 根据位置核对片段名称、道路类型、主道路编号和省份；鼠标停在道路名称或里程说明上可查看分类来源、可信度和里程来源。地图上方也会显示当前定位片段的这些信息。
4. 修改后点击该行“保存修正”；保存所有有改动的行可使用“全部保存”。
5. 希望撤回某条人工分类时，使用“恢复自动分类”。

判断依据可以这样理解：

| 信息 | 怎样使用 |
| --- | --- |
| 分类来源 | 查看分类来自道路编号、道路名称、导航道路类型、综合判断、兜底分类还是人工修正 |
| 可信度 | 高、中、低表示已有分类的可信度；低可信度片段还会标注“待核对”，应结合地图和实际资料检查 |
| 里程来源 | 区分导航里程、按原里程分配、几何估算和人工填写；估算或分配值不能当作车辆实测里程 |

这些信息是判断分类和里程的参考。人工保存后仍应核对范围与编号，不能仅凭“人工修正”或“高”就认定记录准确。

<a id="road-multi-select"></a>

#### 多选片段，先在地图核对再批量保存

1. 在表格左侧勾选需要的片段。可用 Shift 连选、从选择列拖动框选，或使用表头复选框全选。
2. 查看“已选几段”，同时核对上方地图的黄色实线。**地图会同步高亮全部有有效坐标的已选片段**，并调整视野以便检查范围；缺少坐标的片段会单独提示。
3. 修改任意已选可编辑行的道路类型、主编号、省份或共线道路。改动会同步到选中的可编辑片段，应先确认它们确实适用相同内容。
4. 点击“保存选中”。如只想保存一行，使用该行“保存修正”；保存所有有改动的行使用“全部保存”。

**区间标注生成的片段也可以勾选并在地图高亮，但不能在表格直接编辑。** 它们不会被批量修改或“保存选中”改写；需要到上方区间标注列表点击“修改”或“撤销”。因此，“已选几段”不一定等于本次可以批量保存的片段数。

仅点击道路名称用于定位；勾选用于多选核对和批量修改。表格“取消选择”会清除勾选及定位高亮，不会撤回已输入的草稿，也不会清除地图上另行选择的标注区间。保存一行不会自动保存其他行；如提示只保存了部分片段，应核对成功数量，其余草稿仍可继续处理。

道路表格有未保存改动时，上方区间标注暂不可编辑，先保存表格再标区间。切换旅程、日期或路段时，如出现“放弃未保存的道路修正”，点击取消会保留原对象和草稿；确认放弃才会切换。

### 3. 对轨迹的一部分标注道路

**入口：选中人工修正路段 → 轨迹区间道路标注。**

1. 在标注地图的轨迹上依次点击区间起点和终点。
2. 核对高亮虚线是否覆盖需要的范围；需要整段时可点击“整条路段”。
3. 选择道路类型，填写编号；省道和需要省份区分的道路应选择省份。
4. 原道路名称不准确时，填写“道路名称（可选）”；不需要改名称时留空。
5. 点击“保存区间标注”。有虚线预览不代表已经保存。
6. 已有标注可在列表中点击“修改”或“撤销”；选错范围时点击“清除选择”重新选择。

黄色实线是从表格定位或勾选的片段，黄色虚线是正在选择的标注区间。**表格定位和多选不会自动成为标注范围**；仍需在轨迹上点击两个点，或使用“整条路段”。地图范围和表格片段确认清楚后再保存。

修改已有标注时，先点击列表中的“修改”，调整后使用“保存修改”。如果当前标注已有未保存的更改，切换到另一条标注会先询问是否放弃；取消可继续处理当前草稿。“清除选择”会清空当前区间、编号、道路名称、省份和共线等内容，保留所选道路类型；已经保存的标注不会撤销。

标注只改变道路归属，不改变原始轨迹。对只有纯轨迹、没有自动分析的记录，未标注部分保持未知。区间里程会保留按原里程分配或几何估算的来源，不能视作实测数据。

<a id="road-interval-names"></a>

#### 修正区间显示的道路名称

例如某一段实际属于国道，但表格仍显示原路线中的高速名称，可以这样处理：

1. 在地图上选中实际需要修正的起点和终点。
2. 核对道路类型、编号及需要填写的省份。
3. 在“道路名称（可选）”中输入确认后的名称，点击“保存区间标注”。
4. 查看标注列表和下方片段表格，确认新名称及范围正确。

填写的名称作用于**整个所选区间**。区间包含多条不同道路时，应分别标注，避免用一个名称覆盖整段。名称用于显示，道路类型、主编号和省份仍需分别填写。

留空时，各片段沿用自己的原名称。希望取消自定义名称时，在标注列表点击“修改”，清空名称后点击“保存修改”；不需要删除整条标注。原名称有记录时，鼠标停在片段名称或里程说明上可以查看，便于核对修正依据。

### 4. 标注共线道路

同一段物理道路可能同时挂有多个编号，例如一段国道同时属于 `G316` 和 `G210`。应为同一个区间添加共线身份，避免复制轨迹造成总里程重复。

1. 在片段修正或区间标注中，保留正确的主道路类型和主编号。
2. 点击“添加共线道路”。
3. 选择另一条道路的类型，填写完整且匹配的编号；省道和省级高速还需选择省份。
4. 有第三条或更多共线道路时，继续添加。
5. 核对范围后，点击片段或区间的保存按钮。

共线支持高速、国道、省道。如果只有片段中的一部分共线，应在地图上选择那部分区间，不能把整条片段都标为共线。

例如某 10 公里区间同时属于两条国道：两条道路的档案各可计入这 10 公里，但总行驶里程只计一次，道路类型构成按主道路计算一次。**命名道路里程和占比可能重叠，不能将各行相加作为总里程。**

保存后，可搜索各个编号，并在命名道路表、道路档案和道路足迹中核对共线结果。只保存一部分区间时，其他区间仍按各自的道路归属统计。

## 十二、备份、恢复、换电脑与更新软件

### 1. 导出备份

**入口：顶部“备份 → 导出备份”，或 Ctrl + Shift + B。**

1. 先保存当前表单草稿。
2. 点击导出，等待完成。
3. 桌面版选择 ZIP 的保存位置；普通浏览器环境下载 JSON。
4. 确认成功提示，将备份存到容易找到的位置，重要资料可另存到其他磁盘。

备份覆盖当前全部旅程和相关数据，不受地图年份、日期或路段筛选限制。出现导出失败时，应处理错误并重新导出，不能把失败文件当成完整备份。

### 2. 哪些内容包含在备份中

| 内容 | 桌面完整 ZIP | 浏览器 JSON |
| --- | --- | --- |
| 规划和复盘旅程、日期、路段 | 包含 | 包含 |
| 实际记录、评分、标签、备注 | 包含 | 包含 |
| 已保存游记 | 包含 | 包含 |
| 路线缓存、道路分析和人工标注 | 包含 | 包含 |
| 照片库登记、照片索引、照片备注、位置和缩略图 | 包含 | 不包含完整桌面照片资料 |
| 磁盘上的本地原图 | **不包含** | **不包含** |
| 高德 Key | 不包含 | 不包含 |

当前旅程备份格式为 V3，同时兼容 V1、V2、V3 和原始旅程 JSON。日常不需要手工修改文件内部的版本号。

### 3. 恢复备份

**导入是替换恢复，不是把另一份旅程追加进当前资料。**

1. 先导出当前数据，保留恢复前的备份。
2. 点击“备份 → 导入备份”。
3. 选择支持的 ZIP 或 JSON。
4. 完整 ZIP 会显示恢复确认，核对替换范围后确认；桌面 JSON 在校验通过后直接进入恢复，因此选文件前就应完成当前数据备份。
5. 等待成功后，核对旅程数、路线、统计和照片。

完整 ZIP 替换当前全部旅程、路线缓存、照片索引和缩略图。JSON 替换旅程和路线缓存，不能从中恢复缺少的桌面照片资料；不再被旅程引用的旧照片记录也可能被清理。

软件会校验结构，恢复写入失败时尝试回滚。导入前仍应保存自己的备份；失败时保留原文件，根据界面提示处理。

### 4. 换电脑或迁移给另一位用户

1. 在旧电脑导出完整 ZIP。
2. 单独复制所有需要的原图目录，尽量保持内部文件名和目录结构。
3. 在新电脑运行桌面软件。
4. 如新电脑已有资料，先导出它们，再导入旧电脑的 ZIP。
5. 配置自己的高德 Key。
6. 在相册设置中重新关联移动后的原图目录。
7. 检查旅程、道路分析和照片原图，确认迁移结果。

只复制 EXE 不会迁移数据；只复制 ZIP 不能恢复原图文件。

### 5. 更新软件

更新前先导出备份，并保存原图。使用相同正式运行配置、相同 Windows 用户时，新版本通常继续读取原来的本机数据，但开发版、实验包或不同浏览器环境可能使用不同数据位置。

更新后先查看“帮助”中的版本和说明，再检查旅程和相册。版本号相同也可能对应不同打包时间，不能只看版本号判断说明是否更新。

### 6. 本机数据保存在哪里

当前标准 Windows 包使用：

```text
%APPDATA%\roadtrip-retrospective-tool-photo-album-preview\
```

可按 Win + R，输入这一路径打开目录。名称保留了早期相册配置的兼容命名。

目录包含地图 Key 配置、照片索引、缩略图、旅程存储和路线缓存。日常迁移优先用软件备份，不建议直接编辑这些文件。原图仍在你自己选择的照片目录。

开发页面、源码桌面版和正式 EXE 可能使用不同数据目录或地址。浏览器数据也会随浏览器、主机名和端口而隔离，不要通过随意改端口迁移数据。

## 十三、常见问题

### 1. 输入地点后没有联想，或者路线计算失败

依次检查网络、地图服务配置、Key 类型和界面错误。确认使用 Web 服务 Key，并实际选中了起点、终点和每个途经点的候选结果。

如果已经配置 Key 仍失败，按提示核对平台权限或额度。配置成功不代表接口一定可调用。

### 2. 已添加路段，为什么没有显示路线

先在筛选区选中具体旅程、日期和路段。总览不自动批量计算所有缺失路线。再检查地点坐标和网络，必要时使用“重新计算路线、费用和时间”。

### 3. 修改路线以后，道路统计为什么变少了

原分析可能与新起终点、途经点或路线设置不匹配，因而标为过期。先核对新路线，再按需要补全道路分析。旧轨迹能够显示不代表旧分类仍然有效。

### 4. 有地图路线，为什么道路档案或搜索找不到对应编号

路线几何与道路分类是不同资料。可能只有轨迹、分析不完整或已经过期。检查完整性提示，再使用历史分析或人工区间标注。

已保存且有效的共线编号也支持搜索。先核对标注是否已经保存；如果显示读取失败，应先恢复读取，不能把不完整搜索结果当作没有这条记录。

### 5. 点击“全不选”后路线消失了

道路类型模式下，“全不选”隐藏全部五类，包括灰色未知道路。重新勾选需要的类别，或点击“全选”恢复。颜色只是分类结果，不表示道路实时通行状态。

### 6. 为什么规划里程与实际里程不同，或显示“已记录”

规划来自路线结果，实际来自自己填写的记录，两者分别统计。“已记录”可能只覆盖部分路段；未填实际值不会用规划值代替。

### 7. 同一个省道编号为什么出现多行

不同省份的同编号省道分别统计。省份待确认、无编号记录也独立显示。核对省份和道路证据后再修正，不要仅凭编号合并。

### 8. 各条道路里程相加为什么超过总里程

检查是否存在共线区间。每条道路都可计入属于自己的共线里程，命名道路表的行之间会重叠；总行驶里程和道路类型构成只计一次。

### 9. 为什么找不到跨年的旅程

地图、路书和年度统计按旅程开始年份归档；跨年旅程整体归入开始年份。道路档案的记录年份则按每条记录日期筛选。

### 10. 为什么照片扫描完成，相册仍然是空的

扫描只是发现候选文件，还需要选择并关联到当前路段。确认目标路段、取消不必要的日期或文件名筛选，再勾选照片添加。

### 11. 为什么没有相册能力，或者照片没有地图标记

本地照片管理需要桌面复盘环境。没有 GPS 的照片不会自动出现位置，可在详情中手动定位；缺少 EXIF 不代表照片损坏。

### 12. 有缩略图，为什么原图打不开

缩略图和原图分别保存。原图可能被移动、删除、改名，或外接盘未连接。先检查磁盘文件，再重新关联目录或单张照片；只有 ZIP 备份无法还原缺失原图。

### 13. 导出的地图为什么没有底图或缺少部分路线

底图获取失败时降级为路线示意图，文件会保留说明。未保存或不匹配的路线不会凭空补出。回到相应路段检查路线、网络和导出提示。

### 14. 导出 PDF 按钮不可用

直接导出 PDF 需要桌面接口；普通浏览器可下载 HTML，再通过浏览器打印保存为 PDF。加载照片或正在导出时，也需等待完成后再操作。

### 15. 导入备份后，原来的其他旅程不见了

导入会替换当前资料。使用导入前的备份恢复原数据；当前导入不提供两份备份自动追加合并。不要把路书导出当作可恢复备份。

### 16. 导入或导出备份失败

确认文件格式正确、文件完整、目标位置可写和磁盘空间足够。保留原备份和错误提示，不通过改文件版本号绕过检查。

### 17. 软件提示旅程数据损坏或保存失败

数据损坏时，先点击“导出恢复原文”保留原始内容，再决定恢复备份或按界面执行重置。重置会以示例数据替换损坏的旅程数据。

写入失败时，按提示处理存储空间或权限，再使用“重试保存”。不要在未保存成功时继续大量录入或直接关闭。

### 18. 同一台电脑打开另一个版本，为什么旅程不同

开发版、正式版或不同浏览器配置可能对应不同数据位置。确认打开的程序和运行环境，通过备份迁移；不要直接删除旧数据目录。

### 19. 把软件发给朋友，使用说明能打开吗

正常打包的 EXE 自带打包时的说明正文，朋友可以通过“帮助 → 使用说明（README）”离线阅读，无需另附源码。外部链接和在线地图服务仍需要网络。

更新项目 README 后，旧 EXE 内置说明不会自动变化，需要重新打包才会随新程序交付。

### 20. 道路统计、档案或年度回顾突然没有内容

先看页面是否提示“路线分析缓存读取失败”。有提示时，点击“重试读取”；道路相关结果在读取恢复前暂不展示，但旅程里程、驾驶时间和评分仍可查看。读取失败与“没有道路记录”是两种情况，不要为此删除旅程或把里程改成零。

### 21. 待处理清单显示很多可选项目，必须全部填写吗

不需要。实际记录和评分可以留空，只填写自己掌握的资料。默认清单主要帮助核对日期、路线预估和道路分析；勾选“显示可选的实际记录与评分”才会列出这些补充项目。没有待处理项目也不代表记录已经核实无误。

### 22. 点击“查看道路分析”后为什么没有开始计算

这个按钮用于定位待处理路段，并展开分析区域。核对人工修正区选中的旅程、日期、路段和分析范围后，再点击“开始分析”；也可直接修正已有分类或标注区间。

### 23. 地图已经高亮道路，为什么不能直接保存区间标注

点击表格道路名称或勾选产生的黄色实线用于核对片段。新标注需要在地图轨迹上选择起点和终点，形成黄色虚线预览，再填写分类与编号并保存。如果表格还有未保存修改，先保存表格，再操作区间标注。

### 24. 已选多段，为什么有些片段不能修改或保存

先查看它们是否标有“区间标注，请在上方标注列表修改或撤销”。这些片段可以选中并同步高亮，但表格批量修改只处理可编辑片段。到上方标注列表修改对应区间；缺少有效坐标的片段虽然仍在选择中，地图也无法画出高亮。

### 25. 道路类型和编号改对了，为什么名称仍是原来的

片段表格会保留原道路名称，修改分类或编号不一定会改写名称。需要改名时，在“轨迹区间道路标注”中选定范围，填写“道路名称（可选）”并保存。若该区间已有标注，直接在列表点击“修改”。清空自定义名称并保存会恢复沿用原名称。

### 26. 途经点的预计时间是不是到达时间

不是。它是从当前路段起点累计到该点的预计行驶时长，不含出发时间和中途停留。需要安排到达时间时，应另外考虑实际出发时间、游览、休息和其他停留。显示“待计算”时可以手动重新计算；“暂无可靠数据”应保留为未知。

## 十四、快捷键与日常检查清单

### 1. 快捷键

| 快捷键 | 用途 |
| --- | --- |
| Ctrl + K | 打开全局搜索 |
| Ctrl + Shift + B | 快速导出数据备份 |
| Ctrl + S | 在路段详情编辑状态中保存全部 |
| Esc | 关闭使用说明、搜索等支持此操作的弹窗 |
| Shift + 勾选 | 在道路人工修正表中连续选择多行 |

### 2. 出发前

- 核对每一天的日期、起终点、途经点及路段顺序。
- 查看路线、里程、预计驾驶时间和费用，另留游览、休息时间。
- 有途经点时，核对每个点距本路段起点的累计距离与预计行驶时间。
- 保存草稿，导出规划路书并打开检查。
- 导出一份数据备份。

### 3. 旅行结束后

- 将规划旅程转入复盘，核对真实行程。
- 补实际记录、评分、标签和备注，不清楚的数据保留空白。
- 关联照片，检查原图和地图位置。
- 浏览路书，按需要生成游记、导出旅行路书。
- 从待处理清单检查日期、路线预估和道路分析，按需要补全；可选记录只补自己掌握的内容。
- 修正道路时先在地图核对片段或区间范围；保存后再查看名称、编号和共线结果。
- 导出完整 ZIP，并单独备份原图。

## 附录：从源码运行

普通桌面使用者可以跳过本节。项目脚本和打包规则以当前 `package.json` 与 `AGENTS.md` 为准。

### 1. 启动开发页面

在项目根目录打开 PowerShell。准备 Node.js 和 npm，首次安装依赖：

```powershell
npm.cmd ci
```

没有 `.env.local` 时，从 `.env.example` 复制一份；已有文件直接编辑，保留原配置。在其中设置 `AMAP_WEB_API_KEY`，然后运行：

```powershell
npm.cmd run dev
```

默认前端为 `http://localhost:5173`，后端为 `http://127.0.0.1:3001`。浏览器页面设置的 Key 只影响当前后端进程，需要持久配置时使用 `.env.local`。

### 2. 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm.cmd run desktop` | 构建后启动源码 Electron 桌面版 |
| `npm.cmd test` | 执行项目测试 |
| `npm.cmd run build` | TypeScript 检查与前端构建 |
| `npm.cmd run preview` | 预览已构建前端；接口仍需后端 |
| `npm.cmd run package:win` | 标准 Windows x64 便携 EXE 打包 |

标准打包输出为 `release/旅行轨迹记录与规划工具 <版本号>.exe`，当前配置版本为 0.6.6。打包不会自动递增版本号，同版本打包可能覆盖同名产物。源码桌面版和正式包的数据位置可能不同，迁移使用备份。

当前 README 会在前端构建时嵌入软件帮助窗口。更新本文不需要修改业务代码；要让现有 EXE 带上新说明，则需要另行重新打包。

### 3. 开发环境排错

- 测试无法直接导入 `.ts` 时，先检查 Node.js 是否支持默认 TypeScript 类型剥离。
- 前端接口返回 403 时，检查实际访问地址和端口是否符合本地后端来源限制。
- 打包遇到 `powershell.exe ENOENT` 时，先检查 PowerShell 路径和当前进程 PATH。
- 打包遇到文件占用或 `EPERM` 时，先检查本次自行启动的进程，按 `AGENTS.md` 的标准流程处理；不要清空 release 或关闭所有 Node/Electron 程序。

只读演示模式用于展示静态资料，界面会标注“演示版 / 只读模式”，不能用于新增、修改或恢复自己的旅程。
